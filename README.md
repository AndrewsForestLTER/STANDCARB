# STANDCARB

**STANDCARB** is a model to simulate the accumulation of carbon over succession
in mixed-species, mixed-age forest stands.

## Citation

Mark E. Harmon, Barbara Marks, and Narayana Rao Hejeebu. 1996. *A User's Guide
to STANDCARB version 1.0: A model to simulate the carbon stores in forest
stands.*
([Pub No. 2248](https://andrewsforest.oregonstate.edu/publications/2248))
